# ☕ Java Básico — Métodos em Java (Parte 3)

Repositório dedicado às resoluções dos **10 primeiros exercícios** da apostila *Java Básico - Parte 3: Métodos em Java*, desenvolvidos no **IntelliJ IDEA**[cite: 1, 37]. Esta etapa foca na modularização de código por meio de métodos `static`, passagem de parâmetros e diferentes tipos de retorno (`void`, primitivos e `String`)[cite: 37].

## 📋 Exercícios Resolvidos

| Exercício | Método / Tema | Descrição |
| :--- | :--- | :--- |
| `01` | `ola()` | Criação e invocação múltipla de método `void` sem parâmetros para exibição de mensagem. |
| `02` | `mostrarNome(String)` | Passagem de argumento textual para impressão personalizada no console. |
| `03` | `dobro(int)` | Cálculo e retorno do dobro de um número inteiro. |
| `04` | `ehPositivo(int)` | Validação numérica retornando valor lógico (`boolean`). |
| `05` | `somar(int, int)` | Recebimento de dois parâmetros inteiros e retorno da soma. |
| `06` | `exibirIdade(String, int)` | Método sem retorno (`void`) combinando múltiplos tipos de parâmetros. |
| `07` | `quadrado(double)` | Cálculo e retorno da potência ao quadrado de um número decimal. |
| `08` | `maiorDeDois(int, int)` | Comparação entre dois valores inteiros retornando o maior deles. |
| `09` | `saudacao(String)` | Formatação e retorno de uma `String` pronta para exibição. |
| `10` | `parOuImpar(int)` | Verificação de paridade retornando `"PAR"` ou `"IMPAR"`. |
